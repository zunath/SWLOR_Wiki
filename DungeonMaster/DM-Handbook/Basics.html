Dungeon Master Client Basics

The DM Client for SWLOR is a versatile and powerful tool used for running events and overseeing player interaction. Because this tool has a very similar layout to the player client, it allows new quest masters to adjust to the tool very quickly.

1. All players and DM Client users are visible in the party screen - this acts as a quick reference player menu which allows DMs/QMs to find online players quickly. Recent connections are generally shown at the bottom of the scrollable list.

2. All player comms are shown in the left-most chat window. If a player uses SWLOR's version of party chat (comms), it will show up here for all DM Client users to see. This allows DMs to keep up with an event party event while they are in a different cell or out of normal volume range. Tells are not displayed to DMs, as they are considered private and only a server administrator can access these for review.

3. Chooser - This button opens the Chooser Menu, you can also press .

4. Creator - This button opens the Creator Menu, you can also press ,

5. Show Triggers - This button is largely useless on SWLOR due to mechanical overhaul.

6. Appear/Disappear - This button allows a DM/QM to hide or reveal themselves to players for any number of reasons. Depending on whether or not the user is hidden or visible, the button will change accordingly.

7. Pause - This button has been disabled on SWLOR.

8. Difficulty Slider - This tool has been disabled on SWLOR.
 



Your Hotbar

These are some of the most commonly used Commands on the DM Client, while your hotbar doesn't need to look like this at all, this is a general example of a functioning layout:



/copyitem - Copies the item you click on into your inventory. Very handy to have. 

##dm_setfaction Hostile - Sets the clicked NPC to the Hostile faction which will attack Commoner faction 

##dm_setfaction Commoner - Sets the clicked NPC to the Commoner faction which is friendly to players, will not matter if they're in combat though 

/rename - You'll be using this a lot for renaming your NPCs and such. 

DMFI DM Wand - Useful for making sure custom NPC items don't drop when an NPC is killed, changing the time of day, and various other tools to play with. 

DMFI Destroy Object Widget - Deletes whatever you click on, or if you click on the ground, deletes everything within a 2 meter radius. If you use it and click on YOURSELF it'll delete the closest placeable to you.
 
DMFI Voice Widget - Use it on an NPC and you can talk through them by starting your message with a semicolon. 
:For example, this message would get read out by your NPC because it starts with a semicolon. 
Use it on the ground to create a floating invisible The Voice npc. Same idea. 

DMFI Encounter Wand - Has a set number of encounters 1 through 9. Goes hand in hand with the DMFI Encounter Region prefab map we have. You put NPCs in the circles on the map, and summon them with the tool. 

DMFI Target / Appearance Data - Use this in conjunction with the .appearance command to change an NPC or Player's appearance using the appearances.2da file to look up the code. 

Retire XP - This is just a quick way to give out retirement XP. The command is /giverpxp 411125 which is exactly enough XP to hit level 50 in a skill. 

Setscale - This is the /setscale command. I have it to /setscale 1 to quickly restore players to regular height after events. It's good to have one for /setscale 1 and one for /setscale 0.4 since 0.4 is perfect for ships. 

Laigrek - This is just a quickslot for my old DM Avatar. If you use a creature model you have to reset it every time you log in. Useful to have to save typing.

 

Honorary Mention:


DMFI FX Wand - While I don't use it a lot myself, it's very good if you don't like crawling through the visualeffects.2da file.
 

You also have two extra hotbars when holding Shift and Control, same as when you're a player.

My Shift tab is all VFXs. Another important command to have:

##dm_visualeffect ## @@ 

Where ## is the ID number of the visual effect from the visualeffects.2da and @@ is the duration in seconds you want it to last.

Below is the name and ID of the most common ones I personally use: 
Explode (22) - A simple explosion effect. 
Earthquake (286) - Makes the whole screen shake, very useful for a lot of things. 
Red Ghost (561) - Makes for good evil spirits and I also use it to make teleport points more visible. 
Ghost (9) - Our go-to for holograms and general ookie spooky ghosts. 
Purple Ghost (10) - As the other two ghosts, but purple. 
Shadow (14) - Overrides the texture to be a black blob. 
Darkness (1) - As the Darkness spell in base NWN. Will black out an area depending on the scale of the NPC you apply it to. Good for scene transitions or blacking out parts of a map you dont need players going into.
Dust/Miss (460) - Good for landing impacts or "missed attacks" as Intrepid often uses it for. 
Lightning (74) - Single lightning bolt from above. 
Grid (821) - Applies a grid layout to the NPC, size dependent on NPC scale. Scale 10 and Scale 15 are the most popular as of writing.


There are a ton of VFXs, and we have a few custom ones as well. Hop on the DM Client and just play around with them, see what you like.

 

The Creator and You

The Creator window (at the top of the DM Client window or opened by pressing , is one of your main components for setup. It has too much content to go through in a simple setup guide, but some important objects to note are as follows:

SIT is our blank "Sit on this" marker. Useful for a lot of our chairs that aren't set up as chairs or if you want someone to sit on something. The player will sit from the side facing your DM Avatar so when you place it, be directly in front of where you want 'em facing. They can be found under Placeable Object > Custom > Civilization Interior > Furniture > Chairs & Stools

 

Teleport Objects are under Placeables > Custom > Special > Custom 5 > Teleport Object They're blank models that are handy for Point Of Interest markers, Teleport Objects, or whatever you really need them for. They're one of our most useful objects.

The Creator also has the creatures menu. World Creatures stores the stuff actively used on the server on the various planets. If you need a quick NPC that you know is balanced for a certain tier of player this is a good place to go. It's fairly easy to just reskin a gizka or a voritor lizard in a pinch if you need to.

Radial Menus

Most interactions with Player Characters and Non-Player Characters on SWLOR is done through Radial Menus, much like on other Neverwinter Nights Servers:

Using the number pad, users can quickly navigate these menus. Buttons on the radial menu correspond to similar placements on the number pad

Limbo - Send 'em to limbo. Can't send players. Useful for getting rid of NPCs. You can un-Limbo an NPC by pulling them from the Limbo area at the very bottom of the Chooser.

Goto - Jump to 'em. Teleports you right to their location from wherever you are.

Heal - Fully heals them and removes ALL status effects. This includes buffs, debuffs AND any VFXs you applied to them. You can also re-animate dead NPCs by using this with multiple entities selected.

Kill - You'll use this a lot. Just kills 'em. If a player is bugged, 9 times out of 10 killing them and Healing them fixes it.

Take Control - Allows users to take control of NPCs. Does not work on PCs. Note that there are three options below:
 

Toggle Invulnerable - Just makes it so they don't hit 0 HP. Useful if your carefully crafted boss encounter is getting blitzed by 20 players.

Force Rest - Just makes them rest. Advanced Force technique the players can't learn.

More Actions - Brings you to the Player Radial. Only important ones there is the Give/Take Gold section and the Jump To DM command. That's how you give players credits, or take credits away. Don't use the XP buttons or you break their characters.

Radial Menus Cont. - More Actions

More actions are available through this last menu located at the top left of the Radial. This is primarily the same menu you see as a player.

Examine - Allows the user to view the PC/NPC's NWN character sheet, description/SLWOR character sheet, and inventory. User can also leave notes on this character by using the notes tab of the SWLOR character sheet:

Cast Spell - Allows the user to cast a base NWN spell on the target. Due to mechanical changes with SWLOR, some spells don't work as intended and can outright kill a PC/NPC.

Attack - Causes user to attack with currently possessed NPC or as DM. Do not attack players as a DM character - this could result in a server crash.

Special Attack - Similar to Attack, but with a base NWN special attack. Same rules apply as Attack.

Jump to DM - Allows the user to teleport a PC directly to them from anywhere in the module.

Give/Take - This menu is largely broken and can irreparably damage a PC, resulting in a need for a full character rebuild. It should be disregarded. Use only to give Credits.

Special Actions - This menu has a selection of unused tokens. It should be disregarded.

Social Actions - This menu has a selection of social actions that can be used on a player, ex. talk, barter, emote.

Non-Target Specific Radial Menu

The Non-Target Specific Radial Menu has two noteworthy commands which can be accessed by opening the radial menu on a point on the ground: 

Jump All Players to DM - Rarely used, if ever. Provides user with a confirmation dialogue box before jumping all players to the user which prevents large scale server disruption.

Jump to Point - jumps the user to the cursor location. Can also be accomplished by using + key on number pad.

 

Jail

If you ever hear someone go "Take them to Jail" for whatever reason, jail is a side section of the DMFI Custom Encounter Region prefab at the top of the list in the Chooser. Mostly just use it to drag players to an area you can talk to them. Rename them. Reprimand them for trying to mule items after getting perma'd. The usual. 

 

Teleporters & Commands

A quick rundown on teleporters: 
/tptag - sets the tag of the teleporter 
/tpdest - sets the tag that it teleports you to

All the major planets have a waypoint on them called PLANETNAME_LANDING for easy teleporting. 
For example: 
VISCARA_LANDING 
KORRIBAN_LANDING 
DATHOMIR_LANDING 
HUTLAR_LANDING 
TATOOINE_LANDING 

So if you need an easy "okay the event is over go home" teleport. You can just do: /tpdest VISCARA_LANDING and leave it at that. For you, as a DM, you can use /tpwp to teleport to any waypoint in the module. This can be helpful for getting around if you can't find the area in the chooser list sometimes.
